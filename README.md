# Protocol Dice

**Any world. One protocol.**

Protocol Dice is the setting-agnostic core rules and dice system.  
Protocol 7 is the first complete, playtested setting that sits on top of it as the flagship full-system package.

This repository is the clean home for the core engine (mechanics, interactive tools, and guides).  
Setting-specific materials live in their own repositories (starting with `protocol-7`).

## Project intent
Build a setting-agnostic Protocol Dice system whose resolution, dice pools, Edges, Talents, Advancement, and overall play feel stay faithful to the well-playtested Protocol 7 interactive apps (especially the v0.185–v0.188 character and session tools).

Previous attempts in the older `protocol-dice-engine` repository drifted from that feel. This repository starts fresh so the core remains consistent.

## Authority
- Repository state is the source of truth.
- Protocol 7’s playtested interactive materials are the mechanical reference.
- Durable work, decisions, and handoff notes belong in this repository (or the relevant setting repository).
